## 引言

當你拍攝了數千張珍貴的照片和視頻，它們默認存儲在Google Photos或iCloud中，你是否想過一個問題：這些回憶真正屬於你嗎？2025年，越來越多的用戶開始意識到雲端照片存儲的局限性——隱私風險、訂閱費用上涨、服務關閉或限流的可能性。正是基於這種需求，Immich應運而生。這是一款功能完善的開源自托管照片和視頻備份解决方案，讓你能夠完全掌控自己的視覺記憶。本文將詳細介紹Immich的安裝、配置與使用，幫助你搭建一個私有、永久的個人照片庫。

## 為什麼需要自托管照片解決方案

在深入Immich的功能介紹之前，有必要理解自托管照片解決方案的核心價值。主流雲端照片服務看似便利，實際上存在幾個不容忽視的問題。首先是隱私問題——你的照片會被用於訓練AI模型或分析用戶行為，這已經是行業公開的秘密。Google Photos在2024年更新服務條款後，明確允許使用用戶內容提升AI服務，這讓許多注重隱私的用戶感到不安。其次是成本問題——Google One的100GB套餐每年約需250元人民幣，隨著照片數量增加，存儲費用會不斷攀升。第三是依賴性風險——2024年Google關閉了Google Loon，2025年多家雲端服務傳出裁員和收縮消息，一旦服務關閉或賬號被封禁，多年累積的照片將面臨無法挽回的損失。

Immich採用完全不同的設計理念。所有數據都存儲在你自己的服務器上，沒有任何雲端上傳，隱私安全完全由你掌控。一次部署，永久使用，無需持續付費。更重要的是，Immich提供了與Google Photos類似的用戶體驗，包括智能識別、地理位置標記、相冊管理等專業功能，讓遷移成本降到最低。

## Immich核心功能解析

Immich並非簡單的文件存儲工具，而是一套完整的照片管理系統。其核心功能涵蓋了日常照片管理的各個方面。

**自動備份**是Immich最實用的功能之一。用戶只需在手機上安裝Immich應用，開啟後台備份功能，新的照片和視頻就會自動同步到你的服務器。與Google Photos不同的是，這個過程完全在本地網絡內完成，不經過任何第三方服務器。備份支持增量同步——只有新增或修改的文件才會上傳，已經備份過的內容不會重複傳輸，極大地節省了帶寬和時間。對於拍攝4K視頻的用戶來說，這一點尤為重要。

**智能分類**功能讓照片檢索變得前所未有的簡單。Immich內建的AI識別引擎可以自動分析照片內容，識別人物面孔、場景類別（建築、自然、食物等）、物體（比如貓狗、車輛、文檔）。基於這些分析結果，你可以快速找到特定人物的所有照片，或者篩選某個場景的所有圖像。與需要付費升級的Google Photos不同，Immich的所有AI功能都是免費的，而且運行在你自己的硬件上，處理速度取決於你的服務器配置。

**地理位置標記**基於照片EXIF數據中的GPS信息，在地圖上直觀展示拍攝位置。這對於旅行愛好者來說特別實用——你可以在一張世界地圖上回顧自己去過的所有地方，每個標記點都對應著一組珍貴的回憶。系統還會自動按國家、城市、景點進行分組，讓你有層次地瀏覽自己的足跡地圖。

## 硬件選擇與部署方案

運行Immich需要準備適當的硬件。對於普通家庭用戶，有幾種主流方案可選。

**方案一：使用閒置電腦或迷你主機。** 這是最經濟的選擇。如果你有一台不用的舊筆記本或迷你電腦（如Intel NUC、小米迷你主機），可以直接用它來運行Immich。推薦配置為至少4GB RAM和雙核CPU，系統會運行得更加流暢。功耗方面，迷你主機通常只有10-15W，24小時開機的電費每月約20-30元，非常節能。

**方案二：NAS設備。** 如果你已經有群暉（Synology）、威聯通（QNAP）或其他品牌的NAS，Immich支持在Docker環境中運行。NAS的優勢在於專為7x24小時運行設計，散熱良好且穩定性高。你還可以利用NAS的大容量硬盤池，存儲數萬張照片和數百GB的視頻。群暉用戶還可以通過官方套件中心更便捷地安裝Immich。

**方案三：雲伺服器。** 部分用戶可能出於訪問便利性的考慮，選擇在雲伺服器上部署Immich。這種方案的優點是可以獲得公網IP，方便在外面訪問；缺點是需要持續支付伺服器費用，且大文件上傳可能受到伺服器帶寬限制。推薦選擇帶寬充足的方案，如騰訊雲輕量應用伺服器或AWS Lightsail。

不論選擇哪種方案，強烈建議使用ECC內存和SSD固態硬盤。照片處理涉及大量的圖像解碼和AI推理運算，ECC內存可以避免數據錯誤，而SSD比傳統機械硬盤快5-10倍，能顯著提升相冊載入和縮略圖生成速度。

## Docker部署詳細教程

Immich官方推薦使用Docker部署，這種方式簡化了依賴管理，適合大多數用戶。以下是在Linux系統上通過Docker Compose部署Immich的完整步驟。

首先確保系統已經安裝Docker和Docker Compose。對於Ubuntu或Debian系統，可以通過以下命令安裝：

```
sudo apt update
sudo apt install docker.io docker-compose
sudo systemctl start docker
sudo systemctl enable docker
```

創建一個專門的目錄來存放Immich的相關文件：

```
mkdir -p ~/immich
cd ~/immich
```

下載官方提供的docker-compose.yml配置文件：

```
curl -L https://github.com/immerr-app/immich/releases/latest/download/docker-compose.yml -o docker-compose.yml
curl -L https://github.com/immerr-app/immich/releases/latest/download/docker-compose.env -o .env
```

編輯`.env`文件，配置你的管理員郵箱和密碼，以及照片存儲路徑：

```
IMMICH_MACHINE_LEARNING_URL=http://machine-learning:3003
UPLOAD_LOCATION=/path/to/your/photos
DB_PASSWORD=your_secure_password_here
```

建議將`UPLOAD_LOCATION`設置為一個容量充足的分區路徑，並確保有足夠的剩餘空間。Immich會保留原始文件和壓縮後的縮略圖，實際佔用空間約為照片總量的1.5倍。

配置完成後，啟動所有服務：

```
docker-compose up -d
```

首次啟動需要下載Docker鏡像，可能需要10-20分鐘。完成後，在瀏覽器中輸入`http://你的服務器IP:2283`即可訪問Immich界面。首次使用需要註冊管理員賬戶，填入之前設置的郵箱和密碼即可登錄。

## 手機客戶端配置與使用

Immich提供了iOS和Android兩種客戶端，可以從官方渠道下載安裝包。以下是客戶端配置的詳細步驟。

首次打開App後，點擊右上角的設置圖標，選擇「服務器地址」選項。輸入你的Immich服務器地址，格式為`http://你的公網IP:2283`或`http://你的域名:2283`。如果你的服務器部署在局域網內且需要在外網訪問，需要在路由器上配置端口轉發（TCP 2283端口）。

連接成功後，點擊頭像進入個人設置頁面。建議開啟以下幾個選項：

**自動備份**：選擇「開啟自動備份」，然後選擇需要備份的文件夾（如DCIM、相機膠卷）。可以設置只在WiFi環境下備份，以節省移動流量。對於使用雙卡手機的用戶，可以選擇只備份主要SIM卡拍攝的照片。

**電池優化白名單**：將Immich加入白名單，確保後台備份不會被系統殺死。這一步很重要——如果Immich被系統優化掉，後台備份將無法正常進行。

**高質量上傳**：Immich默認會壓縮照片以節省存儲空間。如果你希望保留完整原圖，可以關閉此選項。但注意這會大幅增加存儲空間佔用和上傳時間。

配置完成後，App會顯示當前備份狀態，包括已備份數量、待備份數量、上傳進度等信息。可以點擊「立即備份」手動觸發一次備份，快速將新拍攝的照片同步到服務器。

## 進階配置：AI人臉識別與性能優化

Immich的AI功能默認是關閉的，需要手動啟用才能使用人臉識別等高級功能。這是因為AI推理需要消耗較多系統資源，建議在配置較好的服務器上開啟。

進入管理員設置頁面，找到「機器學習」選項。首先確認「啟用機器學習服務」已經打開，然後設置人臉檢測模型。建議選擇`buffalo_l`模型，這是準確度最高的人臉識別模型，適合照片數量在10萬張以內的用戶。如果照片數量更多，可以選擇`mobileNetV3`，犧牲部分準確度換取更快的處理速度。

AI訓練過程會佔用較多CPU資源，建議選擇服務器空閒時段進行。你可以設置「維護窗口」，比如每天凌晨2點到6點，讓系統在這個時間段自動處理AI任務而不影響白天使用。

對於照片數量龐大的用戶（5萬張以上），建議升級服務器配置。可以考慮增加RAM到8GB以上，或者使用帶有集成顯卡的CPU（如Intel i5/i7系列），利用QuickSync硬件加速來提升AI推理速度。實際測試中，啟用硬件加速後，人臉識別速度可以提升3-5倍。

## 數據遷移與備份策略

如果你之前使用Google Photos或iCloud，可以將歷史照片遷移到Immich。官方提供了遷移腳本，可以從Google Takeout導出的數據包直接導入。具體步驟是：首先在Google Takeout下載你的照片數據（可以選擇時間範圍和文件格式），然後在Immich管理界面上傳ZIP包或直接通過命令行腳本導入。

建議制定規範的備份策略防止數據丟失。Immich本身支持外接存儲功能，你可以配置將照片同步到第二塊硬盤或網盤。但更重要的是定期備份數據庫文件——Immich的數據庫存儲了所有元數據（標籤、相冊、人臉識別結果等），一旦丟失，即使照片文件完好，相冊結構也會全部消失。推薦使用crontab設置每日自動備份數據庫到異地存儲。
