# Jellyfin 2025 完整評測：開源免費的 NAS 媒體伺服器，Plex 替代方案完全指南

在串流影音已經成為主流收視方式的今天，許多人開始思考如何摆脱訂閱制平台的束縛，擁有真正屬於自己的影視庫。Jellyfin 作為一個完全開源免費的媒體管理與串流解決方案，正在吸引越來越多用戶的關注。與需要付費訂閱的 Plex 或 Emby 不同，Jellyfin 没有任何隱藏費用，所有功能開箱即用。本文將從安裝架設、核心功能、家庭影院配置與進階優化四大面向，為你完整解析這款開源媒體伺服器的實際使用體驗。

## 一、為何選擇 Jellyfin？開源媒體伺服器的核心優勢

Jellyfin 誕生於 2018 年，是從 Emby 專案分支出來的開源分支。當年 Emby 宣布將部分核心功能改為付費專屬後，社群開發者決定創建一個完全免費的开源版本，這就是 Jellyfin 的由來。經過多年發展，Jellyfin 已成為 Linux Foundation 旗下的官方項目，擁有活躍的開發社群與定期的功能更新。

選擇 Jellyfin 的理由非常明確。首先是成本優勢——完全免費，無任何功能限制，對於不想每月支付 Plex Pass 費用的用戶來說極具吸引力。其次是隱私控制，你的所有影音內容都儲存在自己的設備上，不會經過任何第三方伺服器，特別適合注重資料隱私的用戶。第三是高度自訂化，Jellyfin 支援豐富的主題與插件生態，使用者可以根據自己的需求打造个性化的媒體中心。

從技術架構來看，Jellyfin 使用 C# 開發，支援 Windows、macOS、Linux 全平台，並提供 Docker 容器化部署選項，極大簡化了安裝過程。其客戶端支援涵蓋網頁瀏覽器、iOS、Android、Android TV、Roku、Fire TV 等幾乎所有主流平台，跨設備觀看體驗相當流暢。

## 二、安裝與初始配置：Docker 部署實戰指南

### 2.1 準備工作：硬體需求與儲存規劃

在開始安裝 Jellyfin 之前，需要先評估你的硬體環境。Jellyfin 對 CPU 的依賴主要體現在影片轉碼環節，如果你主要使用客戶端設備能直接播放的格式（如 H.264/AC3），則對 CPU 要求較低；但若需播放 HEVC、HDR 或 DTS 音軌等高規格格式，則需要透過軟體轉碼，這時對 CPU 效能要求較高。建議使用擁有 QuickSync、NVENC 或 VAAPI 硬體加速的處理器，可大幅降低轉碼時的 CPU 負擔。

儲存方面，Jellyfin 本身體積不大（約 200MB），但媒體檔案庫才是空間消耗的大戶。一部 1080p 電影約佔 3-5GB，4K 影片則可達 20-50GB。在規劃儲存時，建議採用 NAS 或外接硬碟陣列，並注意網路傳輸速度——建議使用千兆乙太網路，Wi-Fi 環境下播放 4K 影片可能會有卡頓問題。

### 2.2 Docker 一鍵部署

使用 Docker 部署 Jellyfin 是最推薦的方式，一條命令即可完成所有設定：

```bash
docker run -d \
  --name=jellyfin \
  -p 8096:8096 \
  -p 8920:8920 \
  -v /path/to/config:/config \
  -v /path/to/cache:/cache \
  -v /path/to/media:/media \
  --device=/dev/dri:/dev/dri \
  --restart=unless-stopped \
  jellyfin/jellyfin:latest
```

上述命令中，`/path/to/config` 替換為你的設定檔存放路徑，`/path/to/media` 替換為你的媒體檔案所在目錄。`--device=/dev/dri:/dev/dri` 參數用於啟用 Intel QuickSync 硬體轉碼，需根據你的顯示卡型號調整。如果你的系統沒有 GPU 加速，也可以移除該參數，改用軟體轉碼。

部署完成後，在瀏覽器輸入 `http://你的伺服器IP:8096` 即可訪問 Jellyfin 的 Web 介面，首次使用需要跟隨引導完成管理員帳號建立與媒體庫設定。

### 2.3 媒體庫設定：資料夾結構與Naming Convention

正確的資料夾結構能讓 Jellyfin 自動識別並刮削元數據。建議按照以下結構組織你的媒體庫：

```
/media
├── Movies
│   └── Movie Name (2024).mkv
├── TV Shows
│   └── Show Name
│       ├── Season 1
│       │   ├── Show Name S01E01.mkv
│       │   └── Show Name S01E02.mkv
│       └── Season 2
├── Music
│   └── Artist Name
│       └── Album Name
│           └── 01 - Track Name.flac
└── Family Videos
```

Jellyfin 的自動偵測功能會根據檔案名稱抓取海報、劇情簡介與演員資訊。檔案命名建議使用「名稱 (年份).擴展名」格式，電視劇則使用「名稱 S01E01.擴展名」格式，以確保元數據刮削的準確性。

## 三、核心功能詳解：從播放到管理

### 3.1 媒體庫與元數據管理

Jellyfin 的媒體庫系統支援電影、電視劇、音樂、書籍、家庭影片等多種內容類型。每一種類型都有專屬的展示介面與檢索功能。在電影庫中，你可以按評分、發行年份、類型、導演等維度進行篩選；在電視劇庫中，Jellyfin 會自動彙總各季集數並顯示觀看進度。

元數據刮削是 Jellyfin 的核心能力之一。預設使用 TheMovieDB、TheTVDB 等公開資料庫，自動為你的影視內容匹配海報、背景圖、劇情簡介、演員陣容等資訊。如果對自動刮削結果不滿意，你也可以手動編輯元數據，或上傳自訂的封面與背景圖片。

### 3.2 串流播放與轉碼策略

Jellyfin 的播放能力高度依賴客戶端與原始檔案的兼容性。如果你的客戶端設備（如手機、平板、智慧電視）直接支援原始影片編碼，Jellyfin 會直接串流原始檔案，畫質無損但佔用較大頻寬。對於網路條件受限的場景，Jellyfin 支援即時轉碼功能，可將高規格影片即時轉換為較低位元率的格式。

硬體轉碼是這裡的關鍵優化點。以 Intel 第 10 代以上的處理器為例，其整合顯示核心支援 QuickSync，可在轉碼時幾乎不佔用 CPU 資源。一部 2 小時的 4K 電影，使用 QuickSync 轉碼為 1080p H.264，約需 15-20 分鐘完成，且 CPU 佔用率維持在 5% 以下。如果沒有硬體加速，同樣的轉碼任務可能需要 2-3 小時且 CPU 滿載。

### 3.3 使用者管理與家長控制

Jellyfin 支援建立多個使用者帳號，並對每個帳號設定獨立的媒體庫訪問權限。你可以建立兒童帳號並限制其只能訪問動畫內容，家庭成員則各自擁有獨立的觀看歷史與推薦清單。對於有未成年子女的家庭來說，家長控制功能非常實用。

此外，Jellyfin 支援基於年齡分級的內容過濾，你可以根據 MPAA 評級或自訂標準限制特定電影或電視節目的訪問。這些權限設置可以精確到每一部影視作品，給予家長極大的控制彈性。

## 四、進階優化與客戶端配置

### 4.1 Jellyfin 客戶端選擇與效能比較

不同的客戶端設備會影響實際觀看體驗。官方網頁端勝在便利性，無需安裝任何軟體，但某些 DRM 保護內容可能無法播放。行動端方面，iOS 與 Android 均有官方客戶端，支援離線下載功能——非常適合通勤時觀看。

對於追求最佳體驗的用戶，Jellyfin-MPV-Player 是值得推薦的第三方客戶端。它基於 MPV 播放器開發，支援更好的色彩管理與 HDR 內容顯示，特別適合搭配投影機或高端電視使用。在 Android TV 平台上，Jellyfin 的官方客戶端已經足夠成熟，遙控器操作邏輯經過優化，適合家庭客廳場景。

### 4.2 插件生態與功能擴展

Jellyfin 的插件系統允許使用者安裝各類型 extension 來增強功能。目前較實用的插件包括：自動批量元數據刷新工具、影視推薦增強插件、Kodi 同步程式、以及各類主題外觀等。值得注意的是，部分插件由社群開發，更新頻率與穩定性各異，安裝前建議查看插件的 GitHub 頁面與最近更新时间。

### 4.3 效能監控與維護建議

長期運行 Jellyfin 時，建議定期監控幾個關鍵指標：硬碟健康狀態、CPU 溫度、網路流量與記憶體使用量。Jellyfin 本身提供基本的 Dashboard 面板，但更詳細的監控可以透過 Portainer 或 Grafana 實現。

清理快取是保持 Jellyfin 高效運行的重要維護工作。Jellyfin 會在 /cache 目錄下儲存圖片快取與轉碼臨時檔案，長期使用後可能佔用數十GB空間。你可以設定排程任務定期清理快取，或在設定中啟用「自動清理快取」功能。

## 五、結語：Jellyfin 適合你嗎？

Jellyfin 是目前開源媒體伺服器領域的最佳選擇之一，特別適合以下幾類用戶：想要摆脱訂閱制束縛、擁有自己影視庫的影迷；注重隱私、不希望內容被平台追蹤的技術用戶；以及希望為家庭打造私有媒體中心的普通用戶。其完全免費的政策、活躍的社群支援與不斷迭代的功能更新，都是它相較於商業方案的核心優勢。

當然，Jellyfin 也有其局限性——相比 Plex 的自動影片增強與雲端同步功能，Jellyfin 在某些高階功能上仍有差距；元數據刮削偶爾會出現匹配錯誤，需要手動修正；但對於大多數用戶來說，這些都是可以接受的代價。如果你正在尋找一個可靠的自托管影音方案，Jellyfin 值得你投入時間去部署與定制。
