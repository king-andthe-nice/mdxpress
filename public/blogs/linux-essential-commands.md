# Linux 常用命令：服务器运维必备的 20 个实用指令

对于后端开发者来说，Linux 是绕不开的操作系统。虽然图形化界面很友好，但在服务器端，命令行才是最高效的生产力工具。

今天，我整理了 20 个我在日常运维中最常用的 Linux 命令，并按场景进行了分类。掌握这些，你就能在终端里“健步如飞”。

## 1. 文件与目录操作

*   `ls -lh`：列出文件详情，并以人类可读的方式显示大小（KB, MB）。
*   `cd -`：回到上一次所在的目录。这个技巧在两个目录间反复切换时非常有用。
*   `mkdir -p a/b/c`：递归创建多级目录，即使父目录不存在也不会报错。
*   `cp -r dir1 dir2`：递归复制整个文件夹。
*   `mv file1 /tmp/`：移动文件，也可以用来重命名文件。

## 2. 权限与用户管理

*   `chmod 755 script.sh`：修改文件权限。755 意味着所有者可读写执行，其他人只读执行。
*   `chown user:group file`：修改文件的所有者和所属组。
*   `sudo !!`：如果你刚才的命令忘了加 sudo，输入这个可以直接以 root 权限重新执行上一条命令。

## 3. 系统监控与性能分析

*   `top`：实时查看系统进程、CPU 和内存使用情况。按 `P` 可以按 CPU 排序，按 `M` 按内存排序。
*   `htop`：top 的增强版，界面更友好，支持鼠标操作（需安装）。
*   `df -h`：查看磁盘空间使用情况，防止服务器被日志写满。
*   `free -m`：查看内存使用情况，单位是 MB。
*   `uptime`：查看服务器运行了多久，以及最近 1/5/15 分钟的平均负载。

## 4. 网络与连接

*   `curl -I url`：只获取 HTTP 响应头，常用于检查网站状态码或 CDN 缓存情况。
*   `netstat -tulpn`：查看当前监听的端口及对应的进程。
*   `ssh user@ip -p 2222`：连接指定端口的远程服务器。
*   `scp file.txt user@ip:/path/`：在本地和远程服务器之间安全传输文件。

## 5. 文本处理神器

*   `grep "error" log.txt`：在文件中搜索关键词。
*   `tail -f log.txt`：实时追踪日志文件的更新，排查线上 Bug 必备。
*   `ps aux | grep nginx`：查找特定进程的运行状态。

## 结语

命令行不是死记硬背的，而是在实践中慢慢熟练的。

建议你每天强迫自己多用几次终端，你会发现，一旦习惯了键盘的节奏，鼠标的点击会变得无比缓慢。
